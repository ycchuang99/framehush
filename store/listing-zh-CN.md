# 简体中文商店信息

## 名称

Framehush

## 简短说明

实时降低 Chrome 标签页中人声的背景噪声。音频在设备上处理，不录音、不上传。

## 详细说明

Framehush 能降低 Chrome 视频与其他播放音频中的人声背景噪声，让你把注意力留给对话与旁白。

在标签页播放音频后，打开 Framehush 并点击“启用降噪”。关闭面板后仍会继续处理。使用完毕后，再次打开 Framehush 并点击“停止降噪”即可结束。

• 使用 RNNoise 实时处理人声背景噪声。
• 音频只在你的设备上处理，不录音、不上传，也不转成文字。
• 无需账号，没有分析追踪或广告。
• 支持简体中文、繁体中文与英文界面，根据浏览器语言自动选择。
• 可用 Alt+Shift+N 打开面板，也能在 Chrome 中调整快捷键。

适合对话与旁白。音乐与音效可能改变，无法保证去除配乐或重叠的人声。音频与视频可能出现轻微延迟。Chrome 内部页面与部分受保护内容不允许捕获。需要 Chrome 116 或更高版本。

权限用途：
• activeTab：通过扩展程序图标使用你选择的标签页。
• tabCapture：在启用降噪后，捕获该标签页的音频。
• offscreen：在面板关闭后，继续执行设备上的音频处理。
