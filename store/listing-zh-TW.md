# 繁體中文商店資訊

## 名稱

Framehush

## 簡短說明

即時降低 Chrome 分頁中人聲的背景雜音。音訊在裝置上處理，不錄音、不上傳。

## 詳細說明

Framehush 能降低 Chrome 影片與其他播放音訊中的人聲背景雜音，讓你把注意力留給對話與旁白。

在分頁播放音訊後，開啟 Framehush 並按「啟用降噪」。關閉面板後仍會繼續處理。使用完畢後，再次開啟 Framehush 並按「停止降噪」即可結束。

• 使用 RNNoise 即時處理人聲背景雜音。
• 音訊只在你的裝置上處理，不錄音、不上傳，也不轉成文字。
• 不需帳戶，沒有分析追蹤或廣告。
• 支援繁體中文、簡體中文與英文介面，依瀏覽器語言自動選擇。
• 可用 Alt+Shift+N 開啟面板，也能在 Chrome 中調整快捷鍵。

適合對話與旁白。音樂與音效可能改變，無法保證移除配樂或重疊的人聲。音訊與影像可能出現些微延遲。Chrome 內部頁面與部分受保護內容不允許擷取。需要 Chrome 116 以上版本。

權限用途：
• activeTab：透過擴充功能圖示使用你選擇的分頁。
• tabCapture：在啟用降噪後，擷取該分頁的音訊。
• offscreen：在面板關閉後，繼續執行裝置上的音訊處理。
